Import guide:
1. Create an empty built-in rp project for Unity 6 or above (use LTS versions)
2. Import package completely ( press Yes button during import to install post processing during import)
3. Restart unity 
4. Open the "Garage" scene and press play

Note 1: You can delete game saved data by pressing "H" key  to delete playerprefs data
Note 2: You can change default settings from the "MainUtility" component attached to the Canvas gamer object int the Garage scene
